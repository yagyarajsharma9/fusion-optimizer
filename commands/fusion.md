# /fusion — Fusion Optimizer

Show current mode, stats, and available commands.

## Usage

/fusion

## Current State
Shows:
- Current operating mode (ZEN / BALANCED / QUALITY)
- Session turn count
- Mode distribution
- Active skills

## Related Commands
- `/fusion-zen` — Force ZEN mode (cost-optimized)
- `/fusion-quality` — Force QUALITY mode (full methodology)
- `/fusion-auto` — Let the system decide
- `/fusion-stats` — Detailed cost savings report
