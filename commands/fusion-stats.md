# /fusion-stats — Cost Savings Report

Display detailed token and cost savings from Fusion Optimizer.

## Usage

/fusion-stats

## Shows
- Mode distribution (ZEN / BALANCED / QUALITY)
- Estimated token breakdown (input, output, saved)
- Cost comparison (with vs without Fusion)
- Active mode and loaded skills

Note: These are estimates based on caveman benchmarks. Actual savings vary by task.
